# Windows: установка и запуск

Для проекта добавлены Windows-скрипты и отдельная обработка завершения процессов.
Разработка и интеграционные проверки выполнены на macOS; фактический запуск на
Windows ещё не проверен. Рекомендуемая конфигурация — Windows 11 x64.
Windows 10 22H2 x64 соответствует требованиям Ollama, но отдельно не тестировалась.
Windows ARM этим руководством не покрывается.

## Что установить

- **Python 3.11 x64** с [python.org](https://www.python.org/downloads/windows/).
  В установщике включите Python Launcher (`py`) и Add Python to PATH.
- **Ollama для Windows** с [официального сайта](https://ollama.com/download/windows)
  — только для компьютера врача, запускающего ИИ. После установки откройте новый терминал.
- Копию **всего проекта**, включая `models/face_landmarker.task`.
  Git необязателен: можно распаковать ZIP в `C:\Projects\Telemedicine`.
- Камеру, микрофон и наушники для звонка. Для чата устройства не нужны.
- Интернет для установки пакетов и загрузки моделей. После установки обработка локальная.

Практический ориентир для врача: 16 ГБ ОЗУ и не менее 12 ГБ свободного места
с учётом окружения, моделей, кешей и Ollama. Это рекомендация, не измеренный
минимум для всех ПК. Видеокарта необязательна, скорость ИИ без неё зависит от CPU.
Для NVIDIA/AMD установите совместимый драйвер по [документации Ollama](https://docs.ollama.com/windows).
У пациента модели не запускаются; достаточно ресурсов для видеозвонка.

Node.js, Docker, WSL, платный API, отдельные Qt и FFmpeg не нужны.
PySide6 включает Qt, PyAV — библиотеки декодирования аудио.
Не копируйте `.venv` с Mac: окружение нужно создать заново на Windows.
Mac-файл `requirements-desktop.lock.txt` не используйте для установки на Windows;
устанавливайте по `requirements-desktop.txt`.

## Установка на компьютере врача

Откройте **PowerShell** в папке проекта:

```powershell
cd "C:\Projects\Telemedicine"
py -3.11 --version
ollama --version
.\setup.cmd
```

Скрипт создаст `.venv`, установит зависимости, скачает Whisper small и Qwen3 4B.
Модели будут в `models\whisper` и `models\ollama`. Загрузка занимает несколько
гигабайт; дождитесь завершения. При сетевой ошибке можно повторить `.\setup.cmd`.
Если файл модели лица отсутствует:

```powershell
.\.venv\Scripts\python.exe download_head_model.py
```

Проверка сервисов без открытия окна:

```powershell
.\run.cmd --check
```

## Два окна на одном Windows-компьютере

В первом терминале:

```powershell
cd "C:\Projects\Telemedicine"
.\run-doctor.cmd
```

Во втором:

```powershell
cd "C:\Projects\Telemedicine"
.\run-patient.cmd
```

У врача нажмите «Я врач • создать», у пациента введите код и нажмите «Я пациент • войти».
Адрес 127.0.0.1 уже задан. Камеру включайте только в одном окне.
Для проверки транскрипта включите обработку у врача и микрофон у пациента;
выключите воспроизведение в обоих окнах, чтобы не было эха.
Пациент увидит очищенные фрагменты и статус, но не сможет запустить/остановить
обработку, редактировать или экспортировать текст через интерфейс.

Ctrl+C во втором терминале закрывает пациента; Ctrl+C в первом закрывает врача
и запущенные им сервисы. Закрытие окна действует так же. Если CMD спросит
`Terminate batch job (Y/N)?`, подтвердите `Y`. Приложение использует Windows Job
Object для удаления своих дочерних процессов; чужая Ollama на 11434 не завершается.

## Два компьютера в одной локальной сети

У врача запускайте **run.cmd**, а не run-doctor.cmd: локальный режим врача
намеренно слушает только 127.0.0.1.

```powershell
.\run.cmd
ipconfig
```

Найдите IPv4 активного Wi-Fi/Ethernet, например `192.168.1.20`.
На отдельном компьютере пациента Python и библиотеки устанавливаются без ИИ:

```powershell
cd "C:\Projects\Telemedicine"
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-patient.txt
.\run.cmd --client-only --host 192.168.1.20
```

Ollama и модели на компьютере пациента не нужны. Для подключения с Mac:
`bash run.sh --client-only --host 192.168.1.20`.

Разрешите Python доступ через брандмауэр Windows для **частной сети** на сервере.
Если диалога не было, можно добавить правило из PowerShell от администратора:

```powershell
New-NetFirewallRule -DisplayName "Telemedicine UDP 5000" -Direction Inbound -Action Allow -Protocol UDP -LocalPort 5000 -Profile Private
```

Порт Ollama 11435 наружу открывать не нужно. При другом UDP-порте укажите
`--port 5001` и врачу, и пациенту, и скорректируйте правило брандмауэра.
Маршрутизатор не должен изолировать Wi-Fi-клиентов. Через интернет/NAT этот
учебный UDP-протокол не рассчитан работать без отдельной доработки.

## Разрешения и устранение проблем

- В Windows: **Параметры → Конфиденциальность и безопасность → Камера / Микрофон**,
  включите доступ для классических приложений. Закройте другие программы, занявшие камеру.
- Выберите микрофон, динамики и номер камеры до входа в комнату. Если звук недоступен,
  попробуйте системное устройство; используемый формат — mono PCM 16 кГц.
- `py` не найден: переустановите Python с Launcher; `ollama` не найдена: установите
  Ollama и откройте новый терминал. Активация venv и изменение ExecutionPolicy не нужны.
- Ошибка `DLL load failed`: проверьте Python x64, переустановите зависимости и
  [Microsoft Visual C++ Redistributable x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).
- Порт занят: закройте прежний запуск через Ctrl+C. Либо используйте
  `.\run.cmd --port 5001 --ollama-port 11436`. Не запускайте два полных сервера
  на одних портах; второй участник должен использовать `--client-only`.
- ИИ медленный: дождитесь первого прогрева, закройте тяжёлые программы.
  Фрагменты появляются после пауз или до 15 секунд непрерывной речи плюс время обработки.
- Логи: `runtime\server.log`, `runtime\ollama.log`. Исходный текст и звук в них не записываются.

## Ограничения и проверки

Очищенный транскрипт передаётся пациенту через сервер и хранится в памяти комнаты.
Новый пациент не получает историю предыдущего. Управление доступно только токену врача.
Это не защита от снимка экрана: пациент видит текст и технически может сохранить увиденное.
ИИ может ошибаться в распознавании и удалении личных данных. Чат и картинки не обезличиваются.
UDP-звонок и передача текста пока не шифруются; используйте локальную тестовую сеть.

Тесты из PowerShell:

```powershell
$env:PYTHONPATH = ".;Telemedicine_Client"
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts/check_desktop.py
```

Официальные требования: [Ollama Windows](https://docs.ollama.com/windows),
[Qt for Python](https://doc.qt.io/qtforpython-6/gettingstarted.html).
