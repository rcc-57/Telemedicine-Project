# Сервер анализа головы

Запускать **вместо** обычного `Lab_Work_two.py`: оба сервера используют порт 5000.
Новый сервер сохраняет комнаты, чат, картинки, видео и звук.

На этом компьютере зависимости и модель уже установлены. Остановите прежний
сервер через Ctrl+C и выполните:

```sh
.venv/bin/python HeadAnalysisServer.py --host 0.0.0.0 --port 5000
```

Клиент:

```sh
.venv/bin/python Client.py
```

Друг запускает обновлённый клиент с `--host IP_СЕРВЕРА`. Передайте ему новый
`Telemedicine_Client.zip`. Библиотека MediaPipe и модель на клиенте не нужны.

## Проверка

1. Первый клиент создаёт комнату (`1`), второй входит как пациент (`2`).
2. Оба открывают окно звонка (`7`), пациент включает камеру.
3. Пациент смотрит прямо и держит голову неподвижно около двух секунд.
4. Появятся рамка лица, углы головы и направления. Медленно поверните голову,
   наклоните её к плечу, кивните и покачайте влево-вправо.
5. Результаты отображаются в обоих окнах и в терминале сервера. При выключении
   камеры вместо прежних углов будет показано, что камера выключена.
6. Кнопка **Калибровка головы** заново задаёт исходное положение и сбрасывает счётчики.
   Во время калибровки снова смотрите прямо. При обнаружении нескольких лиц,
   потере лица или длительном пропуске кадров калибровка выполняется заново.

Анализируется **только видео пациента**. Камера врача для анализа не нужна.
Пациент может проверить анализ даже без открытого окна звонка врача.
Изображение пациента у него самого зеркальное, у врача — обычное. Подписи
«влево/вправо» относятся к изображению врача, а не к анатомическим сторонам пациента.

## Что определяется

- Наличие лица: одно, ни одного или несколько. При нескольких лицах поза не оценивается.
- Поворот (`yaw`), вверх/вниз (`pitch`), наклон к плечу (`roll`) относительно калибровки.
- Изменение положения во времени, повороты влево/вправо, кивки и покачивания.
- Счётчики кивков и покачиваний. Кивок — отклонение вверх/вниз и возврат;
  покачивание — повороты в обе стороны с возвратом в центр.

Поза оценивается по матрице преобразования лица из
[MediaPipe Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker/python).
Кивки и повороты классифицируются нашими пороговыми правилами поверх углов,
а не отдельной обученной моделью жестов. Отклонение нужно выполнять достаточно
заметно: примерно 12° для кивка и 15° для поворота. Кивки распознаются при возврате
за 0,15–2,5 секунды; покачивания — в пределах 3 секунд.

Это приблизительная оценка положения и движения, а не медицинская диагностика
и не точное измерение углов. Закрытое лицо, затылок, сильный поворот, плохой свет
или потеря кадров могут привести к отсутствию результата. Наклон всего корпуса
также меняет положение лица — алгоритм не выделяет отдельно движение шеи.

## Установка сервера на другом компьютере

Нужны `HeadAnalysisServer.py`, `head_analysis.py`, `Lab_Work_two.py`, `media.py`,
`requirements-server.txt`, `download_head_model.py` и папка `models`.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-server.txt
.venv/bin/python download_head_model.py
.venv/bin/python HeadAnalysisServer.py --host 0.0.0.0 --port 5000
```

На Windows замените `.venv/bin/python` на `.venv\Scripts\python`.
На сервере проверено с Python 3.14, macOS Apple Silicon и MediaPipe 1.1.0.
Для другой платформы нужна доступная сборка MediaPipe.
Если раньше установлен `opencv-python`, удалите его перед установкой
`requirements-server.txt`: обе разновидности OpenCV используют модуль `cv2`.
Для совместного запуска клиента и сервера в одном окружении используйте
`opencv-contrib-python`, указанный в обоих файлах зависимостей.

Модель загружается один раз из официального хранилища Google и проверяется по SHA-256.
При обработке кадры не отправляются в интернет и не сохраняются на диск.

## Устройство и проверки

Сервер проверяет токен, комнату, медиасокет и включение камеры. После сборки JPEG
он передаёт последний кадр рабочему потоку (не чаще примерно 8 раз/с на комнату).
В очереди максимум 32 последних кадра разных комнат. Устаревшие кадры пропускаются;
при высокой нагрузке частота анализа снизится. Пересылка звонка не ждёт анализа.
Результаты возвращаются обоим участникам в ответах состояния примерно каждые 0,7 с.
Для чата, звонка и анализа используется один UDP-порт. Обычный сервер без анализа
показывает клиенту «Анализ выключен».

Проверки без камеры:

```sh
python3 -m unittest -v test_udp_server.py test_media.py test_head_analysis.py
```

Дополнительные проверки настоящей модели и окна:

```sh
HEAD_TEST_IMAGE=/путь/к/тестовому_портрету.jpg .venv/bin/python -m unittest -v test_head_model.py
RUN_GUI_TESTS=1 .venv/bin/python -m unittest -v test_call_window.py
```

Тесты движений используют заданные углы. Это проверка логики; точность распознавания
кивков живого человека на двух компьютерах нужно проверить отдельно при хорошем освещении.
