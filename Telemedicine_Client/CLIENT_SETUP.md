# Современный графический клиент

См. [общий запуск](../START_HERE.md) и [полную инструкцию Windows](../README_WINDOWS.md).
Пациент получает транскрипт от врача только для просмотра; модели ему не нужны.

Ниже — инструкция старого консольного клиента и окна Tkinter.

# Клиент: чат, картинки, камера и звук

Держите рядом файлы `Client.py`, `VideoCall.py`, `media.py`, `requirements-client.txt`.
Нужен Python 3 с Tkinter. Сервер должен быть обновлён до версии с видеозвонками.

## Установка на Windows

В терминале папки клиента:

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements-client.txt
.venv\Scripts\python Client.py --host 192.168.1.10 --port 5000
```

Замените `192.168.1.10` на IP компьютера с сервером.
В установщике Python должен быть выбран компонент Tcl/Tk.

## Установка на macOS

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-client.txt
.venv/bin/python Client.py --host 192.168.1.10 --port 5000
```

Для Homebrew Python 3.14 модуль Tkinter устанавливается командой
`brew install python-tk@3.14`. Для другой версии Python нужен соответствующий пакет.
В основном проекте окружение `.venv` уже подготовлено.
В IDE выберите интерпретатор `.venv/bin/python` этого проекта.

## Как позвонить

1. Врач запускает клиент и выбирает `1` — создать комнату.
2. Пациент запускает клиент с IP сервера, выбирает `2` и вводит код комнаты.
3. Оба выбирают `7` — открыть окно видеозвонка.
4. В окне нажмите **Включить камеру** и **Включить микрофон**.
5. Повторное нажатие отключает соответствующее устройство.
6. **Выключить звук** отключает воспроизведение голоса собеседника, сохраняя ваш микрофон.
7. **Завершить звонок** закрывает окно и освобождает устройства. Участие в комнате
   сохраняется: можно продолжить чат командами `4`–`6` или выйти командой `3`.

Пока окно звонка открыто, консольное меню ожидает его закрытия.
Камера и микрофон изначально выключены. Звук собеседника изначально включён,
если доступно устройство вывода. На macOS/Windows разрешите Python или приложению
терминала доступ к камере и микрофону, когда система его запросит.

Если запущен `HeadAnalysisServer.py`, под видео появится анализ головы пациента:
наличие лица, повороты, наклоны и кивки. Сначала пациенту нужно посмотреть прямо
и не двигать головой около двух секунд. Кнопка **Калибровка головы** повторяет
эту настройку. Дополнительные библиотеки анализа на компьютере друга не нужны.
Результаты приблизительные; направления относятся к незеркальному видео врача.

При обновлении старого окружения, в котором был пакет `opencv-python`, сначала
удалите его (`.venv/bin/python -m pip uninstall opencv-python`), затем установите
новый `requirements-client.txt`. Теперь используется `opencv-contrib-python`,
совместимый с сервером анализа. На Windows используйте `.venv\Scripts\python`.

Используйте наушники: в этой учебной версии нет эхоподавления.
На одном компьютере два клиента могут конфликтовать за одну камеру —
для полноценной проверки используйте два компьютера.

## Выбор устройств

`--camera 1` выбирает вторую веб-камеру (по умолчанию `0`).
Список аудиоустройств:

```sh
.venv/bin/python -m sounddevice
```

На Windows используйте `.venv\Scripts\python -m sounddevice`.
Номера можно передать через `--input-device N` и `--output-device N`.
Если устройство не поддерживает mono 16000 Гц, выберите другое.
На Linux также могут понадобиться системные пакеты Tkinter и PortAudio.

## Сеть и ограничения

Сервер: `python3 Lab_Work_two.py --host 0.0.0.0 --port 5000`.
Ему необходимы `Lab_Work_two.py` и `media.py`; библиотеки камеры на сервере не нужны.
Видео и звук проходят через тот же UDP-порт 5000. Входящие подключения разрешаются
в брандмауэре сервера; проброс портов для одной локальной сети не нужен.

Видео — JPEG 480×360, до 12 кадров/с; звук — mono PCM 16 бит, 16000 Гц.
Неполные или устаревшие кадры отбрасываются, пропуски аудио заполняются тишиной.
Потоки не записываются в файлы. Это собственный UDP-протокол для учебной локальной
сети, без шифрования и возможностей WebRTC. При потере пакетов возможны паузы
и рывки. Сервер хранит комнату один час с момента создания.

Документация библиотек:
[OpenCV VideoCapture](https://docs.opencv.org/4.x/dd/d43/tutorial_py_video_display.html),
[sounddevice Raw Streams](https://python-sounddevice.readthedocs.io/en/latest/api/raw-streams.html),
[Tkinter для Homebrew Python 3.14](https://formulae.brew.sh/formula/python-tk@3.14).
